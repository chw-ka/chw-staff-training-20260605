# Cursor 快速開始

> **本文件已精簡。** 課堂**唔使**手動 set model、唔使填 Gemini / DeepSeek API Key。  
> Agent 右上角選 **Auto**，跟 Demo Login 或 Cursor 訂閱即用。

---

## 3 步開始

1. 跟 [`08-appendix-安裝清單.md`](08-appendix-安裝清單.md) — 安裝 Cursor、Demo Login、Open Folder
2. `Ctrl + I`（Mac：`Cmd + I`）開 **Agent**，Model 選 **Auto**
3. 打開 [`02-prompt-cheatsheet.md`](02-prompt-cheatsheet.md)，由活動一開始貼 Prompt

---

## 點解唔使 set model？

| 活動 | Agent 做咩 | 實際用咩 |
|------|-----------|----------|
| 活動一 Phase 1 | 寫 Python code、跑 terminal | **Whisper**（本機 script，唔經 AI 連線） |
| 活動一 Phase 2–3 | 讀檔、跟 SKILL 寫紀錄 | Cursor Agent（**Auto**） |
| 活動二 | 本機整理 `activity-2-files/` | Cursor Agent（**Auto**） |
| 活動三 | 靜態網站小工具 | Cursor Agent（**Auto**） |

> ⚠️ **請勿**將 API Key 貼入 Agent 對話。
