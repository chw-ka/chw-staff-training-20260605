# Cursor 快速開始

> **本文件已精簡。** 課堂**無需**手動設定模型、**無需**填寫 Gemini／DeepSeek API Key。  
> 請於 Agent 視窗右上角選擇 **Auto**，並依 Demo Login 或 Cursor 訂閱使用即可。  
> **Workflow、SKILL、MCP、排版文字（.md）** 等術語 → 見 [`00-core-concepts-glossary.md`](00-core-concepts-glossary.md)。

---

## 三步開始

1. 依照 [`08-appendix-安裝清單.md`](08-appendix-安裝清單.md) — 安裝 Cursor、完成 Demo Login、Open Folder
2. 按 `Ctrl + I`（Mac：`Cmd + I`）開啟 **Agent**，Model 選 **Auto**
3. 開啟 [`02-prompt-cheatsheet.md`](02-prompt-cheatsheet.md)，由活動一開始貼上 Prompt

---

## 為何無需手動設定模型？

| 活動 | Agent 角色 | 實際使用 |
|------|-----------|----------|
| 活動一 Phase 1 | 撰寫 Python 程式、執行終端機 | **Whisper**（本機 script，不經 AI 連線） |
| 活動一 Phase 2–3 | 讀檔、依 SKILL 撰寫紀錄 | Cursor Agent（**Auto**） |
| 活動二 | 本機整理 `activity-2-files/` | Cursor Agent（**Auto**） |
| 活動三 | 靜態網站小工具 | Cursor Agent（**Auto**） |

> ⚠️ **請勿**將 API Key 貼入 Agent 對話。
