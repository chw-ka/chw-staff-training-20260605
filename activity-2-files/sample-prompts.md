# 活動二 Prompt — 先傾清楚，再執行

> Model 用 **Auto**。  
> 開啟 **`activity-2-files`** 資料夾做本活動（已內附 SKILL、RULES）。

---

## 階段 A：傾談（唔改檔，2–5 分鐘）

```
@.cursor/skills/file-organizer/SKILL.md

我個下載 folder 好亂，想整理，但唔想打長篇指示。

請用繁體中文書面語同我傾：
1. 我係中學老師，有教學、行政、eLearning、ICT、STEAM 等工作
2. 我想點分類、舊檔點處理、會唔會改名
3. inbox/ 大約有 100 個檔，你可否先講你會點樣讀內容再分類

呢個階段只傾，唔好搬任何檔。
```

---

## 階段 B：定規則（更新 profile，3–5 分鐘）

```
根據剛才傾談，請：
1. 以 @my_organization_profile.example.md 為底，寫一份 my_organization_profile.md（跟我的偏好改）
2. 確認 @folder_structure.md 同 sorted/ 子資料夾一致
3. 列出分類規則等我確認，我確認後先至執行
```

---

## 階段 C：一句執行（課堂高潮）

> 確認規則後，**只貼呢句**：

```
@.cursor/skills/file-organizer/SKILL.md
@my_organization_profile.md
@folder_structure.md

請按 SKILL 階段 C：讀 @inbox/ 每個檔內容（唔好只睇副檔名），
搬入 sorted/<類別>/<學年>/ 或 sorted/<類別>/跨學年/（跨學年檔唔好硬塞單一學年）。
逐步等我批准。完成後俾我摘要表（含類別、學年）。
```

（若未建立 `my_organization_profile.md`，將 `@my_organization_profile.md` 改為 `@my_organization_profile.example.md`）

---

## 課堂捷徑（時間唔夠）

講者預先確認 `my_organization_profile.example.md`，學員可直接貼**階段 C**。
