## 目標資料夾結構

**第一層：工作類別** → **第二層：學年／跨學年**

### 第一層 — 類別

| 類別 | 放咩 |
|------|------|
| `教學/` | 教案、worksheet、評核、試卷、課程表 |
| `行政/` | 通告、表格、報名、合約、報價、財務、場刊 |
| `eLearning/` | 網上學習、NC、課程映射、教師帳號 |
| `ICT/` | IT Lab、Python、AI、技術文件 |
| `STEAM/` | STEAM 計劃、比賽、工具 |
| `圖片素材/` | 純圖片、封面、課堂用圖 |
| `待確認/` | 睇唔清類別或學年 |
| `old/` | 明顯舊版 |
| `trash/` | 建議丟棄（唔分子學年） |

### 第二層 — 學年與跨學年

| 子 folder | 何時用 |
|-----------|--------|
| `2025-2026/` | 內容**只屬**本學年 |
| `2024-2025/` | 只屬上一學年 |
| `2023-2024/` | 只屬再上一學年 |
| **`跨學年/`** | **橫跨多個學年**、常年政策、多年通用指引、唔綁單一學年的總表／架構 |
| `_學年不明/` | 讀完仍無法判斷 |

> **跨學年 vs 單學年：** 若檔案標題或內容寫「2024–2026」「各學年適用」「全年」「校本政策」而唔係某一屆 — 入 **`跨學年/`**，唔好硬塞入 `2025-2026/`。  
> 類別**根目錄**（`sorted/教學/檔名`）僅在極少數情況使用；**優先**用學年或 `跨學年/` 子夾。

---

## 學年判斷

1. **單一學年** → `2025-2026/`、`2024-2025/` 等（見檔名 `2526`、`2425` 或內文明確一個學年）
2. **跨學年** → `跨學年/`（多年、常年、政策總覽、不限定一屆）
3. 同一主題有新版 → 舊版入 `old/<學年>/` 或 `old/跨學年/`
4. 仍唔肯定 → `待確認/_學年不明/`

---

## 分類原則

1. **讀內容為主**
2. **唔好為咗有學年 folder 而亂估學年** — 唔肯定是否跨學年時，用 `跨學年/` 或 `待確認/`
3. **唔刪除**：除非我明確批准
