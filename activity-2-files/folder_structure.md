# 目標資料夾結構

每個**工作類別**底下，按需要放入**學年**或**跨學年**子資料夾。

```
activity-2-files/
├── inbox/
└── sorted/
    ├── 教學/
    │   ├── 2025-2026/      ← 只屬本學年
    │   ├── 2024-2025/
    │   ├── 2023-2024/
    │   ├── 跨學年/         ← 橫跨多個學年、政策、常年適用
    │   └── _學年不明/
    ├── 行政/ …（同上）
    ├── eLearning/ …
    ├── ICT/ …
    ├── STEAM/ …
    ├── 圖片素材/ …
    ├── 待確認/ …
    ├── old/ …
    └── trash/              ← 唔分子學年
```

## 搬檔路徑（三種）

| 情況 | 路徑 |
|------|------|
| 清楚屬於**單一學年** | `sorted/<類別>/<學年>/<檔名>` |
| **跨學年**、常年政策、多年通用 | `sorted/<類別>/跨學年/<檔名>` |
| 類別根目錄（可選） | `sorted/<類別>/<檔名>` — 僅當 profile 允許且內容確實唔適合放入任何子夾 |

**例子：**
- `sorted/ICT/2025-2026/Tender_IT_Lab.docx` — 本學年標書
- `sorted/行政/跨學年/學校行事曆總表.xlsx` — 多年適用
- `sorted/教學/2024-2025/S2_評核.docx`

Agent：讀內容 → 定**類別** → 定**學年或跨學年** → 搬檔。
