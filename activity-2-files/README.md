# 活動二：本機文件整理 — 先傾清楚，再執行

> **Open Folder 開本資料夾**即可。內附 **SKILL、RULES、整理偏好、目標 folder**。  
> 示範：`inbox/` 約 **100 個**下載檔（已篩選私隱風險；**唔會**改你真正 Downloads）。

---

## 痛點（講者開場）

我哋其實**每天都要執檔名、執 folder**，唔覺察都唔知花咗幾多時間。  
有同事**桌面一大堆檔**，連桌面係點都搵唔返。  
Cursor 可以幫你執 — **點執都得** — 但一定要有**明確指示**。  
唔想打長篇字？**先同 Agent 傾清楚想點執**，再 set 規則，最後先執行。

---

## 三階段（唔按副檔名分類）

| 階段 | 做咩 | 改唔改檔 |
|------|------|----------|
| **A 傾談** | 講你的角色、想點分類、舊檔點算 | ❌ 唔搬 |
| **B 定規則** | 更新 `my_organization_profile.md`、`sorted/` 結構 | ❌ 唔搬 |
| **C 執行** | Agent **讀每個檔內容**（標題、首段、表頭…）再入 folder | ✅ 逐步批准 |

**重點：** 唔好「PDF 入一個 folder」— 要睇**內容**係教學定行政定 ICT…  
路徑：**單學年** `sorted/類別/2025-2026/…`；**跨學年** `sorted/類別/跨學年/…`。  
唔確定 → `待確認/`；舊檔 → `old/`；建議丟棄 → `trash/`。

## 快速開始

1. Cursor → Open Folder → **`activity-2-files`**
2. `Ctrl + I` → Model **Auto**
3. 跟 [`sample-prompts.md`](sample-prompts.md)：**A → B → C**（時間唔夠可直做 C）
