# 校徽及 AI 插圖素材

## school-logo.png

講者課前請放入此資料夾：

- **檔名：** `school-logo.png`
- **建議尺寸：** 200×200 px 或更高
- **格式：** PNG，透明底為佳
- **用途：** MARP global footer

若課堂來不及準備，可暫用 placeholder：

```markdown
footer: '迦密聖道中學 CHW'
```

## AI 插圖（活動三）

Agent 可將 Gemini 生成的插圖存為：

- `assets/illustration-exhibition.png`
- `assets/illustration-timetable.png`
- `assets/illustration-ai-policy.png`

在 MARP 中引用：

```markdown
![bg left:40%](assets/illustration-exhibition.png)
```

## 輸出

Agent 生成的簡報建議存放於：

```
activity-3-marp/output/morning-briefing.md
```
