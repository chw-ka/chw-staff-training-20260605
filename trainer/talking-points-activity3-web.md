# 活動三講解要點 — 教學用互動網頁（60–85 min）

> 素材：[`activity-3-web/`](../activity-3-web/) · 上線：[`handouts/07-static-site-publish.md`](../handouts/07-static-site-publish.md)  
> **定位：** 唔係整行政小工具 — 係整俾**學生用瀏覽器玩、做、學**嘅一頁式互動頁（Simulation / 互動練習 / 簡單 Game）。

---

## 開場（2 min）

**話術：**

> 「活動一、二幫你處理**行政**；活動三幫你處理**課堂**。
> 你想學生**拖曳、按掣、即時睇結果** — 以前可能要搵 IT 或買平台；
> 而家你用自然語言描述**教學情境**，叫 Agent 寫 **HTML + CSS + JS**，
> 本機 preview，課後仲可以放上 **`teacher.chw.edu.hk`** 俾全班開。」

**三種常見形態（投影一表就够）：**

| 類型 | 例子 | 適合科目 |
|------|------|----------|
| **Simulation 模擬** | 調節 pH、电路接駁、力嘅分解 | 化學、物理、通識 |
| **互動練習** | 選擇題 + 即時解釋、填空檢查 | 中文、英文、歷史 |
| **簡單 Game** | 限時配對、闖關計分、翻牌記憶 | 任何科 — 溫習、詞彙 |

**展示（30 秒）：** 用瀏覽器打開 `activity-3-web/starter/index.html` —  
> 「starter 只係示範**互動邏輯**（按掣 → 即時結果）；課堂我哋會改做**你哋科嘅內容**。」

## 講者 Demo 前 — 揀一個「Wow 場景」（課前定好）

**建議用視藝科／通識向、全班都明嘅例子 live 生成：**

| 優先 | Demo 主題 | 一句 Prompt 方向 |
|------|-----------|------------------|
| ★ 推薦 | **色彩混合 Simulation** | 三原色 slider → 即時 preview 混合色 + 色名 |
| 備選 A | **中史時間軸配對 Game** | 6 個事件卡片拖去正確年份 |
| 備選 B | **英文 Vocab 配對** | 限時 60 秒，詞彙 ↔ 中文解釋，計分 |

> **原則：** 一個畫面、一個核心互動、**30 秒內**學生就明玩咩。

---

## Demo 流程（約 15–18 min）

| 步驟 | 動作 |
|------|------|
| 1 | 口述教學情境（見下方「講者主推 Prompt」） |
| 2 | Agent Model：**Auto** |
| 3 | 貼 Prompt → Allow 生成到 `activity-3-web/output/` |
| 4 | 完成後 **雙擊 `output/index.html`** 或拖入 Chrome — **全班 Wow** |
| 5 | 即場改一句：「加計分」「加下一題掣」「錯咗顯示解釋」 |
| 6 | （可選 30 秒）口述 `_web` 上線 — 詳見 07 講義 |

### 講者主推 Prompt（色彩混合 Simulation — 投影用）

```
請幫我用純 HTML + CSS + Vanilla JS 做一個「中學視覺藝術 — 三原色混合」教學 Simulation。

教學目標：學生調節 RGB 滑桿，即時睇混合色同色名，理解加色法。

要求：
1. 輸出到 activity-3-web/output/：index.html、styles.css、app.js
2. 畫面：左側三個 slider（紅/綠/藍 0–255），右側一個大色塊 + 顯示 HEX 色碼
3. 底部簡短說明（香港繁中書面語）：三原色、加色法各一句
4. 互動：拖 slider 即時更新，唔使撳「生成」
5. UI：清晰、適合投影同 iPad，mobile 一欄排列
6. 完成後話我點用瀏覽器打開 index.html 預覽
```

**必講收束（Vibe Coding）：**

> 「你唔使識寫 code — 你係 **老闘兼科主管**：
> 講清楚**學習目標、互動步驟、對錯回饋、用咩語言**；
> Agent 出檔，你 **Approve**、**preview**、**試玩一次**先俾學生。」

## 全班練習（約 5–8 min）

**指令（照讀）：**

> 「用 5 分鐘，諗你**自己科**一個可以一頁做晒嘅互動：
> Simulation、練習、或者 Game 都得 — 貼 Prompt，輸出到 `output/`。」

**按科組給靈感（口頭提示即可）：**

| 科組 | 可做的互動 |
|------|------------|
| 中文 | 錯別字選擇題 — 選完顯示正確寫法同解釋 |
| 英文 | 文法填空 — 輸入後 check，錯就 highlight |
| 數學 | 一元二次方程 — 改 a,b,c 即時畫拋物線（簡化版） |
| 科學 | pH 指示劑變色 — 拖 pH 值，色條同文字解釋跟住變 |
| 歷史 | 史料排序 — 四張卡拖去時間先後 |
| 地理 | 香港天氣符號配對 — 圖示拖去正確名稱 |
| 公民 | 持份者立場 — 選議題後顯示不同持份者觀點卡片 |
| ICT | 邏輯閘 — 點擊 AND/OR 輸入，睇 output 0/1 |

**時間緊：** 學員只改講者 Demo 嘅**標題、色系、一條說明文字**（仍算完成）。

---

## 寫 Prompt 四要素（必講，1 min）

跟學員講，好 Prompt 要包含：

1. **科目 + 課題** — 「中二科學 — 酸鹼度」「中三歷史 — 辛亥革命」
2. **學生做咩** — 拖、按、輸入、配對、限時？
3. **即時回饋** — 對/錯提示、分數、解釋、下一題
4. **輸出規格** — `activity-3-web/output/`、繁中、要 responsive

**範例一句（精簡版）：**

```
請做一個中二科學 pH 模擬：slider 0–14，右邊顯示酸/鹼/中性同一句解釋，繁中，輸出到 activity-3-web/output/。
```

> 「**唔使 PowerPoint、唔使搵 IT 寫 App** —
> 你描述教學情境，幾分鐘後學生喺瀏覽器**玩緊你設計嘅 Simulation**；
> 複製去 NAS `_web`，全班 homework 都開同一個網址。」

## 常見問題（即場）

| 問題 | 答 |
|------|-----|
| 打開係白畫面？ | 確認開 `output/index.html`；叫 Agent 檢查 JS 錯誤 |
| 互動冇反應？ | 「請確保 slider / 按掣有綁 event，改完再 preview」 |
| 太複雜 / 好慢？ | 「簡化做一個互動、一個畫面；刪除動畫同多餘關卡」 |
| 內容有錯？ | **你係把關者** — 同改會議紀錄一樣，試玩後修正文字同數值 |
| 可以放真實試題？ | 可以，但**公開網站 = 公開**；測驗卷慎放 `_web` |
| API Key 寫入 JS？ | **唔好** — 靜態網頁任何人都可以 view source |
| 同 PowerPoint 有咩分別？ | PPT 係**播**；呢個係**做** — 學生操作先有結果 |

## 時間不足

| 剩餘 | 做法 |
|------|------|
| 少 5 min | 講者跑完 Simulation Demo；學員只睇 + 記 Prompt 四要素 |
| 少 10 min | 跳全班練習；派 02 handout 活動三變體，課後自己做 |
| 少 15 min | 只講概念 + 播放預先準備好嘅 `output/` 成品（課前講者生成） |
