# 40–60 min｜活動二：本機文件整理 — 講者話術

---

## 1. 開場痛點（約 2 分鐘）

**建議原句照講：**

> 「我哋其實**每天都要執檔名、執 folder**，唔覺察都唔知花咗幾多時間。  
> 有啲同事**桌面一大堆檔**，就嚟連**桌面係點都搵唔返**。  
> 其實我哋都可以用 Cursor 幫手執 — **點執都得** — 但一定要有**明確指示**先得。  
> 唔想打字打太多？你可以**先同 Agent 傾清楚想點執**，先至 set 規則同 SKILL，**再執行**。」

---

## 2. 示範情境（約 2 分鐘）

> 「呢度 `inbox/` 有接近 **100 個檔**，全部都係下載 folder 縮影 — 自己都唔知邊個打邊個。  
> 不如叫 Agent **幫你快啲讀一讀** — 睇標題、首段、Excel 表頭 — 佢明白內容，又知你係老師（教學、行政、eLearning、ICT、STEAM…），  
> 就會幫你入啱 folder；舊檔可以入 `old/`，明顯垃圾可以入 `trash/` — **唔係按 PDF、Word 分類**。」

**動作：** 展開 `activity-2-files/inbox/`，指幾個亂檔名 `(1)(2)`。

---

## 3. 開啟活動資料夾（約 1 分鐘）

> 「大家 **Open Folder → `activity-2-files`**。  
> 入面已經有 **SKILL、RULES、整理偏好範例、目標 folder 結構**。  
> 你唔使由零寫指示。」

指 `.cursor/skills/file-organizer/`、`my_organization_profile.example.md`、`sorted/`（每類下有學年 + **`跨學年/`**）。

---

## 4. 三階段課堂節奏

| 階段 | 時間 | 學員做咩 | 講者強調 |
|------|------|----------|----------|
| **A 傾談** | 3–5 min | 貼 `handouts/prompt-cheatsheet.md` 階段 A | **唔搬檔**，只傾 |
| **B 定規則** | 3–5 min | 貼階段 B，產生 `my_organization_profile.md` | 確認規則先 |
| **C 執行** | 10–12 min | 貼**一句**階段 C | 逐步 **Approve**，睇 `sorted/` 郁 |

**Wow 話術：**

> 「傾完一句執行，左邊檔案自己入籃 — 教學、行政、ICT… 唔使你自己逐個拖。」

---

## 5. 驗收（約 2 分鐘）

- [ ] 有單學年（`ICT/2025-2026/`）同跨學年（`行政/跨學年/`）兩種路徑
- [ ] 有 `待確認/` 都正常（代表 Agent 唔亂估）
- [ ] 總檔案數約 100（inbox 清空或剩少量）
- [ ] 強調：課堂只動 **project 內** 檔，唔改你真正 Downloads／桌面

---

## 6. 課後（30 秒）

- 複製 `my_organization_profile.example.md` → 改成自己科組
- 用自己 Downloads 備份練習（**勿** commit 學生資料到 git）
- Google Drive 版：**唔喺課堂講** → [`handouts/09-google-drive-self-study.md`](../handouts/09-google-drive-self-study.md)

## 核心概念（投影用）

| 概念 | 一句 |
|------|------|
