# 講者 On-Stage Checklist — 現場 Demo 不出錯

> 面向非技術教職員的 Cursor 示範，用以下五項減少「技術恐慌」。

---

## 1. 字要大 — 全場看得清

- 連按 **`Ctrl + =`**（Mac：`Cmd + =`）**3–4 次**放大編輯器字體
- Agent 回覆區同樣放大；投影前用「觀眾席最後一排」試看
- 若投影仍細：Cursor **Settings → General → Editor: Font Size** 調到 18–20

---

## 2. 藏起「 scary 」側欄 — 不要嚇到同事

- **`Ctrl + B`**（Mac：`Cmd + B`）隱藏左側檔案樹
- Demo 時只留：**中間文字** + **右邊 Agent 對話**
- 需要 `@` 引用檔案時先短暫打開，選完即關

話術：
> 「左邊那一堆是檔案清單，今日不必理。我們集中看中間與右邊 — 你與 AI 對話的地方。」

---

## 3. 預先開好「乾淨桌面」

- 關閉無關 browser tab、通知、Teams popup
- 開好要 demo 的 tab：**Cursor** + **Google Drive**（活動二）或 **PowerPoint**（VBA demo）
- 課前跑完 [`pre-class-checklist.md`](pre-class-checklist.md) 與 [`demo-script.md`](demo-script.md)

---

## 4. AI 出錯 / 慢 — 不必慌

話術（背熟）：
> 「A.I. 都會出錯，這個時候我們只要做兩件事：第一，**不要亂按** — 等它跑完或者按 Stop；第二，**改一句 Prompt 再試**，好像教學生改作文一樣。AI 是草稿，你是 editor。」

若 live lag：
- 切去 **課前預跑的 output 檔**（`expected-output-sample.md` 等）繼續講概念
- 話：「若網絡較慢，我們先看預先執行好的結果 — 流程相同。」

---

## 5. Markdown 預覽 — 30 秒講清「# 不是壞了」

1. 開一份 `.md` 檔，指著 `#` 與 `**`：
   > 「這些符號好像亂碼，其實是**排版標記**，與 Word 的標題樣式一樣。」
2. 按 **`Ctrl + Shift + V`**（Mac：`Cmd + Shift + V`）開 **Preview**，或右上角分屏圖示
3. 指著預覽：
   > 「看，同一份文件 — 左邊是編輯，右邊是印出來的樣式。複製到 Word 也可以。」

詳見 [`demo-chaotic-transcript/markdown-preview-walkthrough.md`](demo-chaotic-transcript/markdown-preview-walkthrough.md)

## 快速鍵速查（Windows / Mac）

| 動作 | Windows | Mac |
|------|---------|-----|
| 放大字體 | `Ctrl + =` | `Cmd + =` |
| 隱藏側欄 | `Ctrl + B` | `Cmd + B` |
| Agent 視窗 | `Ctrl + I` | `Cmd + I` |
| Markdown 預覽 | `Ctrl + Shift + V` | `Cmd + Shift + V` |
